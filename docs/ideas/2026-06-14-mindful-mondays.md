# Mindful Mondays — a day-scoped intervention regime

A weekly reset day: remove dopamine triggers (digital first, eventually physical) and prevent in-depth implementation. The operator's idea, 2026-06-14.

## Fit with the intervention model

Mindful Monday = a **regime**: several interventions sharing `delivery = Monday` (a calendar trigger — a new delivery condition alongside standing / JITAI / threshold). Not state-adaptive; scheduled.

**Two halves, both compose existing keel:**

1. **Remove dopamine triggers (digital)** — cue-removal (BCT 12.3 reduce-cue-exposure / 12.1 restructure-environment), `delivery = Monday`, `surface = browser`, aimed at the *whole watchlist* (shorts, feed, netflix, chess…), not just shorts. = Prong A cue-removal + a `getDay()===1` trigger condition.

2. **Prevent in-depth implementation** — reuse the gate + appetite/granularity:
   - **Soft (recommended, catch-and-steer):** Monday forces appetite → coarse + fires the existing wind-down granularity nudge ("high-level only, no deep multi-file dives"), retargeted from "late" to "Monday." The agent self-limits to think/review.
   - **Hard (sovereign pact):** Monday blocks `Edit/Write/Bash` with the skip escape — a *recurring* park/sign-off. Enforced but escapable. Start soft; escalate only if soft doesn't hold.

## Why it fits

keel already treats Monday specially — weekly-review is Monday-gated with implementation off; `morning` detects Monday. Mindful Monday extends that ethos from the morning ritual to the whole day.

## Experiment

Monday-vs-rest-of-week is a built-in **alternating-treatments** design. Measure: sign-off (subjective — did the week start clearer? less rumination?) + drift log (objective — did Monday drift drop with cue-removal on?).

## Boundary (honest)

keel = digital only (browser/agent/desktop). The "eventually otherwise" (physical dopamine triggers) is **off-keyboard** — phone / environment / Things checklist, like the wake-up ritual. keel owns the digital arm and can *remind* about the physical; it cannot enforce the physical.

## Cost

Small — mostly a `day-of-week` trigger condition + retargeting existing pieces (cue-removal, appetite/granularity, the gate). Sequencing: **after** intervention v0 (Prong A + breath-gap) proves the cue-removal + measurement loop. Don't build standalone.
