## The move

While `keel focus` is on, the windowed drift set (YouTube, chess, etc.) gets a soft breath-to-continue interstitial on the browser surface. A focus-scoped, gentler sibling of the existing drogue.

## Why follow-up, not v0

- **Different surface** (browser extension): can't share the agent slice's plumbing. Bundling turns one `small` pitch into a `medium`.
- **Gated on v0's evidence.** v0 logs `focus_on/off`, so the gap-fill EDA can ask whether the agent-side breath + capture nudge *alone* drops browser drift. Add friction only if the gentle nudge proves insufficient. Catch-and-steer before walls.

## Shape (when it comes)

- Scoped to focus-on only (user-invoked, so sovereignty stays intact). Friction only while you chose the mode.
- A **soft speed bump, not a hard cutoff** (hard cutoffs hit 6-10% adoption per the research basis). Breath-to-continue, not a block. Defensive friction guarding what you chose.
- Reuse the **drogue** plumbing.

## Claim discipline / equanimitech

Nudge not block, scoreless, fade-able. A hard cutoff or a streak would be equanimitech-washing.
