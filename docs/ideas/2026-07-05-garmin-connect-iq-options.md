# Garmin Connect IQ options

Connect IQ is open — Monkey C language, VS Code tooling, sideload via USB without store approval. Three app types worth considering IF ever needed: Widget/Glance (pull-only, most equanimitech), Data Field (live during activity), Watch Face (always visible).
