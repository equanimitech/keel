# keel-gate v0 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship the smallest thing that stops late-night coding-with-Claude *today*: a Claude Code hook gate that, past a configured hard-stop, denies coding tool calls (Edit/Write/Bash/…) until a reset hour — escapable only by a scarce skip credit — plus a wind-down nudge + meta-awareness "bell" before the wall, and a scoreless daily reflection. **Pure hooks. No Tauri daemon, no browser.**

**Architecture:** One self-contained Node ESM script `keel.mjs` lives in the repo, symlinked to `~/.keel/keel.mjs`. Three Claude Code hooks (`PreToolUse`, `UserPromptSubmit`, `SessionStart`) in `~/.claude/settings.json` invoke it. It reads `~/.keel/config.json` + `~/.keel/state.json` + the clock, decides, prints the hook contract. **Fail-open**: any error/missing file → exit 0, allow (never trap the machine). "Am I coding?" is implicit — the hook only runs inside Claude Code.

**This is the first real instance of the strategy model, configured as a target + friction rules** — not a bespoke shape. So v0 seeds the real model instead of needing a rewrite:
- a **target** `claude-code` (the scope `f` is keyed by),
- a **wind-down driver** (intention × clock) → `f ∈ [0,1]`,
- **friction rules** = Drogue renderers, each `{ notch, engagesAt, tools, arming }` on the drag scale `hide<dim<delay<blur<block`. v0 ships one rule: `{ notch:"block", engagesAt:1.0, tools:[…] }` — the config shape already supports more.
- **Compass-orient** (reveal, not friction): the wind-down nudge + bell while `0 < f < 1`.
- **skip credits**: spending one suppresses the block until the next reset.

**Tech stack:** Node ≥18 ESM (`.mjs`, no build), `node:test`, `node:fs`/`os`/`path`. No deps.

**Lineage:** scoped slice of `docs/superpowers/specs/2026-06-01-keel-ai-gate-design.md`; vocabulary per `docs/superpowers/specs/2026-06-01-keel-strategy.md` (the desktop **Drogue** `block` notch). Deliberately omits (build later): breakpoint-arming (needs the observer — v0 block is `immediate`), the Tauri daemon, the focus MCP, hard-to-quit relaunch, the shared `Friction`/`frictionCurve` core (v0 inlines a linear ramp; refactor onto the core at umbrella step 3).

## Friction derivation (the core logic)

`f` from the wind-down driver, night wraps midnight (`windDown 23:30 > reset 05:00`):
- **day** (outside `[windDown, reset)`) → `f = 0` (silent).
- **wind_down** (`[windDown, hardStop)`) → **linear ramp** `0 → 1` (progressive friction; drives the orient nudge).
- **lockdown** (`[hardStop, reset)`) → `f = 1` (the `block` rule fires).

The pre-tool hook applies any rule whose `f ≥ engagesAt` and whose `tools` include the called tool. A spent skip credit holds `f` below the block rule's `engagesAt` until the next reset.

```js
#!/usr/bin/env node
// keel-gate v0 — Claude Code focus hook. Target + friction rules. Pure helpers + dispatch.

export function toMin(hhmm) {
  const [h, m] = String(hhmm).split(":").map(Number);
  return h * 60 + m;
}

// nowMin inside half-open [start,end), wrapping midnight if start > end?
export function inWindow(nowMin, start, end) {
  return start > end ? nowMin >= start || nowMin < end : nowMin >= start && nowMin < end;
}

// wind-down driver → f ∈ [0,1]: 0 day · linear ramp windDown→hardStop · 1 lockdown.
export function frictionAt(nowMin, driver) {
  const w = toMin(driver.windDown), h = toMin(driver.hardStop), r = toMin(driver.reset);
  if (!inWindow(nowMin, w, r)) return 0;          // day
  if (inWindow(nowMin, h, r)) return 1;           // lockdown
  const span = ((h - w + 1440) % 1440) || 1;      // windDown→hardStop, wrapping
  const into = (nowMin - w + 1440) % 1440;
  return Math.max(0, Math.min(1, into / span));   // wind_down ramp
}

export function phaseOf(f) {
  if (f <= 0) return "day";
  if (f >= 1) return "lockdown";
  return "wind_down";
}
```

```js
import { readFileSync, writeFileSync, mkdirSync, existsSync } from "node:fs";
import { homedir } from "node:os";
import { join } from "node:path";

export const KEEL_DIR = join(homedir(), ".keel");
const CONFIG_PATH = join(KEEL_DIR, "config.json");
const STATE_PATH = join(KEEL_DIR, "state.json");
export const TARGET_ID = "claude-code";

const DEFAULT_TARGET = {
  driver: { kind: "wind-down", windDown: "23:30", hardStop: "01:00", reset: "05:00" },
  rules: [{ notch: "block", engagesAt: 1.0, arming: "immediate",
            tools: ["Edit", "Write", "MultiEdit", "NotebookEdit", "Bash"] }],
  orient: { bellAfterMin: 120, sessionGapMin: 30 },
  skipBudget: { perMonth: 2, cap: 3 },
};

export function loadConfig() {
  try { return JSON.parse(readFileSync(CONFIG_PATH, "utf8")); } catch { return {}; }
}
// The active target, with defaults filled in.
export function loadTarget(cfg = loadConfig(), id = TARGET_ID) {
  const t = cfg.targets?.[id] ?? {};
  return {
    driver: { ...DEFAULT_TARGET.driver, ...t.driver },
    rules: t.rules ?? DEFAULT_TARGET.rules,
    orient: { ...DEFAULT_TARGET.orient, ...t.orient },
    skipBudget: { ...DEFAULT_TARGET.skipBudget, ...t.skipBudget },
  };
}

export function loadState() {
  try { return JSON.parse(readFileSync(STATE_PATH, "utf8")); }
  catch { return { credits: 0, creditsMonth: "", skipUntilTs: 0, sessionStartTs: 0, lastPromptTs: 0, nights: {} }; }
}
export function saveState(s) {
  if (!existsSync(KEEL_DIR)) mkdirSync(KEEL_DIR, { recursive: true });
  writeFileSync(STATE_PATH, JSON.stringify(s, null, 2));
}

export function refillCredits(state, target, monthKey) {
  if (state.creditsMonth === monthKey) return state;
  return { ...state, credits: target.skipBudget.perMonth, creditsMonth: monthKey };
}
export function spendSkip(state, skipUntilTs) {
  if ((state.credits ?? 0) <= 0) return { spent: false, state };
  return { spent: true, state: { ...state, credits: state.credits - 1, skipUntilTs } };
}
```

```js
export function updateSession(state, nowTs, orient) {
  const gapMs = orient.sessionGapMin * 60_000;
  const fresh = !state.lastPromptTs || nowTs - state.lastPromptTs > gapMs;
  return { ...state, sessionStartTs: fresh ? nowTs : state.sessionStartTs, lastPromptTs: nowTs };
}
export function unbrokenMin(state, nowTs) {
  return state.sessionStartTs ? Math.floor((nowTs - state.sessionStartTs) / 60_000) : 0;
}
```

- [ ] **Step 1: Add stdin, time helpers, rule application, handlers, CLI**

```js
function readStdin() {
  return new Promise((res) => {
    if (process.stdin.isTTY) return res("");
    let d = ""; process.stdin.on("data", (c) => (d += c)); process.stdin.on("end", () => res(d));
  });
}
function safeParse(s) { try { return JSON.parse(s); } catch { return null; } }
function nowMinOf(now) { const d = new Date(now); return d.getHours() * 60 + d.getMinutes(); }
function monthKey(now) { return new Date(now).toISOString().slice(0, 7); }

// Reset instant of the current keel-night (epoch ms) — for skipUntil + night keys.
export function nextResetTs(now, driver) {
  const r = toMin(driver.reset);
  const cand = new Date(now); cand.setHours(0, 0, 0, 0); cand.setMinutes(r);
  if (now >= cand.getTime()) cand.setDate(cand.getDate() + 1);
  return cand.getTime();
}
function nightKey(now, driver) { return new Date(nextResetTs(now, driver)).toISOString().slice(0, 10); }
const skipActive = (state, now) => now < (state.skipUntilTs ?? 0);

// Which rule (if any) denies this tool right now? null = allow.
export function denyingRule(target, f, toolName, state, now) {
  if (skipActive(state, now)) return null;                       // credit lifts the block
  return target.rules.find((rule) =>
    rule.notch === "block" && f >= rule.engagesAt && (rule.tools ?? []).includes(toolName)) ?? null;
}

function emit(obj) { if (obj) process.stdout.write(JSON.stringify(obj)); process.exit(0); }
function emitText(t) { if (t) process.stdout.write(t); process.exit(0); }

async function handlePreTool(now) {
  const target = loadTarget();
  const f = frictionAt(nowMinOf(now), target.driver);
  let state = loadState();
  const input = safeParse(await readStdin());
  const rule = denyingRule(target, f, input?.tool_name, state, now);
  if (!rule) return emit(null);                                  // allow (silent)
  saveState(recordNight(state, now, target.driver, { reached: true }));
  const reason = `keel: wind-down. Coding paused until ${target.driver.reset}. ` +
    `Spend a skip credit to override: \`node ~/.keel/keel.mjs skip\` (${state.credits ?? 0} left).`;
  return emit({ hookSpecificOutput: { hookEventName: "PreToolUse", permissionDecision: "deny", permissionDecisionReason: reason } });
}

async function handleUserSubmit(now) {
  const target = loadTarget();
  const f = frictionAt(nowMinOf(now), target.driver);
  const phase = phaseOf(f);
  let state = updateSession(loadState(), now, target.orient);
  saveState(state);
  if (phase === "day") return emitText("");                     // invisible
  const dur = unbrokenMin(state, now);
  const bell = dur >= target.orient.bellAfterMin
    ? ` You've been at it ${Math.floor(dur / 60)}h unbroken — worth landing the current thread.` : "";
  if (phase === "lockdown" && !skipActive(state, now)) {
    return emitText(`[keel] Coding is paused until ${target.driver.reset} (wind-down). ` +
      `Conversation is fine; to write code, spend a skip credit: \`node ~/.keel/keel.mjs skip\`.${bell}`);
  }
  const hhmm = new Date(now).toTimeString().slice(0, 5);
  return emitText(`[keel] ${hhmm} — winding down. Favor landing open work over starting something large.${bell}`);
}

function handleSessionStart(now) {
  const target = loadTarget();
  const state = refillCredits(loadState(), target, monthKey(now));
  saveState(state);
  const last7 = lastNNights(state, target.driver, now, 7);
  if (!last7.length) return emitText("");
  const held = last7.filter((n) => n.held).length;
  return emitText(`[keel] wound down on your own ${held} of the last ${last7.length} night(s). ${state.credits} skip credit(s) this month.`);
}

export function recordNight(state, now, driver, patch) {
  const key = nightKey(now, driver);
  const nights = { ...(state.nights || {}) };
  nights[key] = { ...(nights[key] || {}), ...patch };
  return { ...state, nights };
}
export function lastNNights(state, driver, now, n) {
  const out = [];
  for (let i = 1; i <= n; i++) {
    const key = nightKey(now - i * 86_400_000, driver);
    const rec = state.nights?.[key];
    if (rec) out.push({ key, held: !!rec.reached && !rec.skipped });
  }
  return out;
}

async function main() {
  const [cmd, sub] = process.argv.slice(2);
  const now = Date.now();
  if (cmd === "hook") {
    if (sub === "pre-tool") return handlePreTool(now);
    if (sub === "user-submit") return handleUserSubmit(now);
    if (sub === "session-start") return handleSessionStart(now);
    return process.exit(0);
  }
  if (cmd === "skip") return cmdSkip(now);
  if (cmd === "status") return cmdStatus(now);
  console.log("usage: keel <hook pre-tool|user-submit|session-start | skip | status>");
}
main().catch(() => process.exit(0)); // fail-open: a hook error must never block the user
```

```js
function cmdSkip(now) {
  const target = loadTarget();
  const refilled = refillCredits(loadState(), target, monthKey(now));
  const { spent, state } = spendSkip(refilled, nextResetTs(now, target.driver));
  if (!spent) { console.log(`keel: 0 skip credits left — coding stays paused until ${target.driver.reset}.`); return; }
  saveState(recordNight(state, now, target.driver, { skipped: true }));
  console.log(`keel: skip spent. Coding unblocked until ${target.driver.reset}. ${state.credits} credit(s) left this month.`);
}

function cmdStatus(now) {
  const target = loadTarget();
  const f = frictionAt(nowMinOf(now), target.driver);
  const state = refillCredits(loadState(), target, monthKey(now));
  const locked = phaseOf(f) === "lockdown" && !skipActive(state, now);
  console.log(`keel[${TARGET_ID}]: f=${f.toFixed(2)} phase=${phaseOf(f)}${locked ? " (LOCKED)" : ""} ` +
    `credits=${state.credits} windDown=${target.driver.windDown} hardStop=${target.driver.hardStop} reset=${target.driver.reset}`);
}
```
