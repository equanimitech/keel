# keel presets

Copy one of these to `~/.keel/config.json` and make it yours — every string in
`voice` is meant to be replaced with *your own words*; a borrowed voice fades,
yours doesn't. Run `keel rules` to see what's in effect.

- **wind-down.json** — the committed night gate: scarce skips (2/month), a vice
  window, the full ramp. Tighten or loosen freely; the override is always one
  command (`keel skip`, `keel unpark`) and removal is always one config block.
- **wind-down-gentle.json** — the same shape with generous skips (4/month), no
  vice window. A low-stakes way to feel the gate before committing to anything
  stricter.

Two principles these presets honor (and yours should too): the override stays
easier than the block, and defaults start generous — you tighten, never the
other way around.
